# GameHub audio

The background track and effects are bundled locally so the games do not depend on a third-party audio server. These source assets are released under CC0; attribution is optional.

- `background-bossa.mp3` — “Bossa Nova” by Joth, [OpenGameArt](https://opengameart.org/content/bossa-nova).
- `caro-place.ogg`, `caro-place-2.ogg` — “Boardgame piece wobbles” by Aidan Walker, [OpenGameArt](https://opengameart.org/content/boardgame-piece-wobbles).
- `poker-shuffle.ogg`, `poker-card.ogg`, `poker-chips.ogg` — “Casino Audio” by Kenney, [Kenney](https://kenney.nl/assets/casino-audio).
- `win-jingle.ogg` — “Win Jingle” by Fupi, [OpenGameArt](https://opengameart.org/content/win-jingle).
